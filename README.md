# sc-stPCA


***********************************************************************************************************

1. System requirements

a. The codes can be run within MATLAB environment.

b. We implemented the codes with MATLAB R2024a on Windows.

c. No non-standard hardware is required.

***********************************************************************************************************

2. Installation guide

The MATLAB codes can be run directly without installation.

***********************************************************************************************************

3. Sample codes

I. For coupled-Lorenz model simulation, run "compare_Lorenz_stPCA_scstPCA_for_short";

II. For representative bifurcation models simulation, run "main_bifurcation_scstPCA".

III. For the paleoclimate records, run "Dante_Cave_data_preprocessing.m" to preprocess the data, and run "dante_scstPCA.m" to obtain the 1D representation.

IV. For the radar-based heavy-rainfall data, run "region_CR_data_try_scstpca.m" to obtain the 1D representation, and run "Warning_Gold_Standard_Analysis.m" to perform early-warning analysis.
